# Research Idea Report

**Direction**: C 线 offline RL：低成本复现 / 摊销 SSAR-IQL trusted-action signal  
**Generated**: 2026-05-12 21:44 CST  
**Ideas evaluated**: 9 generated -> 6 survived filtering -> 0 piloted -> 3 recommended  
**Status**: first-pass idea report; no GPU pilot launched in this pass.

## Landscape Summary

当前 C 线已经不是“baseline 能不能跑”的阶段。`hopper-medium-replay-v2` seed0 上，TD3+BC 弱，ReBRAC-lite 有基本信号，PRDC/A2PR 官方源码当前 gate 下没有明显收益；SSAR cached IQL-qv 很强，但去掉 IQL action selection 后掉分明显。补充 IQL/CQL 后，结论进一步收紧：IQL 本身是强 baseline，SSAR 不能只和 TD3+BC 比。

最近文献也支持这个判断。SSAR 直接把问题定义成不同 state / action 质量下，不应该使用固定 regularization 强度；它引入 state-adaptive regularization，并选择性约束高质量动作。NeurIPS 2024 的 value-bottleneck 文章进一步提醒：offline RL 的瓶颈不一定只是 value learning，policy extraction 和 test-time state generalization 也很关键。2025 年 SORL / EVOR 一类工作则把 value function 当作 verifier / rejection sampler，用于 candidate action selection 或 inference-time scaling。

因此，C 线最有价值的问题不是“再跑哪个 baseline”，而是：

> 已经有强 value / trusted-action signal 时，能不能把它变成便宜、可复用、可解释的 selector，而不是每个 env/seed 都付一次完整 IQL-qv / SSAR 预筛成本？

## Recommended Ideas

### Idea 1: ATLAS - Amortized Trusted-Action Label Selector

- **Hypothesis**: SSAR/IQL 的主要价值可以蒸馏成一个轻量 selector `g_phi(s, a)` 或 `g_phi(s)`，用来预测哪些 dataset actions 值得强 BC regularization；训练这个 selector 远便宜于每次重跑完整 IQL-qv。
- **Minimum experiment**: 在 `hopper-medium-replay-v2` seed0 上，用已有 SSAR/IQL cache 产生 trusted label / beta weight；训练一个小 MLP selector；把 `trusted_td3_bc.py` 的 BC weight 换成 selector 预测值；跑 50k。
- **Expected outcome**: 如果 50k final/best 超过 ReBRAC-lite 34.48，并且 100k 不像 return-ranked selector 一样掉回 20s，说明有正信号。
- **Novelty**: 7/10. closest work: SSAR 用 IQL-qv 做 selection，但没有把 expensive teacher signal 显式蒸馏成 cheap selector。
- **Feasibility**: 高。需要读取现有 cache / teacher score，训练一个小模型，预计首个 pilot < 1 GPU-hour。
- **Risk**: MEDIUM.
- **Contribution type**: method + diagnostic.
- **Pilot result**: SKIPPED. 推荐作为第一个实现。
- **Reviewer's likely objection**: 可能被认为只是“distill SSAR”；需要证明成本下降、跨 seed/env 或跨 algorithm 复用，而不只是复制一个 seed。
- **Why we should do this**: 它最贴当前实验事实：SSAR 强、IQL selection 关键、cheap online selector 失败。

### Idea 2: Light-IQL Warmup Selector

- **Hypothesis**: 完整 IQL-qv 预筛很贵，但 trusted-action ordering 可能在短 warmup 后已经足够稳定；用 10k/20k light-IQL value labels 可能捕获主要排序信号。
- **Minimum experiment**: 训练 10k、20k、50k 三档 IQL value/critic teacher；分别生成 advantage / trusted weights；接入 `trusted_td3_bc.py` 跑 50k。先比较 label agreement 和 final score。
- **Expected outcome**: 如果 20k teacher + TD3+BC selector 能接近 IQL/SSAR signal，同时成本明显低于 full IQL-qv，方向成立。
- **Novelty**: 6/10. closest work: IQL / SSAR，但重点转为 teacher cost scaling 和 early label sufficiency。
- **Feasibility**: 高。已有 IQL compact baseline；需要加 label export。
- **Risk**: MEDIUM.
- **Contribution type**: method + cost analysis.
- **Pilot result**: SKIPPED.
- **Reviewer's likely objection**: 需要证明不是只在 hopper seed0 偶然成立。
- **Why we should do this**: 比直接蒸馏更容易先做出来，也能直接回答“SSAR 的贵是否必要”。

### Idea 3: Value-Guided Policy Extraction Diagnostic

- **Hypothesis**: 在固定 value signal 下，性能差异可能主要来自 policy extraction，而不是 value 本身；不同 extraction operator 对同一 IQL/SSAR value 的利用效率不同。
- **Minimum experiment**: 固定 IQL value/Q teacher，比较 3 种 extraction：AWR-style weighted BC、TD3+BC-style actor update、candidate action re-ranking / rejection。只跑 `hopper-medium-replay-v2` seed0，先 50k 或 even eval-only candidate reranking。
- **Expected outcome**: 如果 candidate re-ranking 或 behavior-constrained policy gradient 显著优于 weighted BC，说明主线可转成 extraction mechanism。
- **Novelty**: 7/10. closest work: NeurIPS 2024 value-bottleneck paper，SORL/EVOR 的 value verifier 思路。
- **Feasibility**: 中。需要统一 teacher API 和 candidate action generator；可以先用 Gaussian BC policy 采样 N=10 action。
- **Risk**: MEDIUM.
- **Contribution type**: diagnostic + possible method.
- **Pilot result**: SKIPPED.
- **Reviewer's likely objection**: 如果只是复现 Park et al. 的 policy extraction 结论，创新不够；需要和 SSAR/IQL trusted-action amortization 结合。
- **Why we should do this**: 它能解释为什么 IQL best 很高但 final 波动，也能解释 cheap selector 为什么失败。

### Idea 4: Uncertainty-Calibrated Trusted Selector

- **Hypothesis**: online Q-gap selector 失败不是因为 Q-gap 方向错，而是单 critic 太噪；用 bootstrap ensemble / dropout uncertainty 做 lower-confidence-bound advantage，可以避免过度相信错误高 Q。
- **Minimum experiment**: 训练 3 个小 critic 或 dropout critic，计算 `LCB(Q_data - Q_policy)` 作为 BC weight；50k gate。
- **Expected outcome**: 分数至少超过 Q-gap online 的 19.94，并接近或超过 ReBRAC-lite 34.48。
- **Novelty**: 5/10. uncertainty in offline RL 很常见，但用于 cheap SSAR-style trusted-action replacement 有一定项目内价值。
- **Feasibility**: 中。实现成本不高，但多 critic 会加一点训练时间。
- **Risk**: MEDIUM-HIGH.
- **Contribution type**: method.
- **Pilot result**: SKIPPED.
- **Reviewer's likely objection**: 容易被看成普通 ensemble trick；需要和 IQL/SSAR label agreement 绑定。
- **Why we should do this**: 它是 Q-gap 失败后的合理修正，但我不建议排在 ATLAS / Light-IQL 前面。

### Idea 5: Adaptive Regularization Controller With Target Trust Fraction

- **Hypothesis**: 固定 BC coefficient 或固定 trusted fraction 不稳；如果训练过程中控制 trusted fraction / policy deviation 到一个目标范围，能减少 return-ranked selector 50k 高、100k 掉的现象。
- **Minimum experiment**: 在 `trusted_td3_bc.py` 中加入动态 beta/controller：根据最近 Q-gap distribution、policy-action distance 或 selected fraction 自动调节 BC weight；50k gate。
- **Expected outcome**: 不一定冲到 SSAR，但如果曲线比 return-ranked selector 稳定，能成为 robustification 组件。
- **Novelty**: 4/10. ASPC 等 adaptive policy constraint 已经很接近。
- **Feasibility**: 高。
- **Risk**: LOW-MEDIUM.
- **Contribution type**: engineering method / ablation.
- **Pilot result**: SKIPPED.
- **Reviewer's likely objection**: 新意弱，除非和 teacher-label amortization 结合。
- **Why we should do this**: 可作为 ATLAS 或 Light-IQL 的 stabilizer，不应单独作为主 idea。

### Idea 6: Cross-Algorithm Trusted Signal Reuse

- **Hypothesis**: 如果 IQL/SSAR trusted labels 真的是 dataset quality signal，它们应该能迁移到不同 actor-update algorithms，比如 TD3+BC、ReBRAC-lite、A2PR，而不只服务 SSAR。
- **Minimum experiment**: 用同一份 teacher labels 分别加到 TD3+BC 和 ReBRAC-lite 的 actor regularization；比较 50k。
- **Expected outcome**: 如果同一 label 在两个算法上都有提升，这就是项目级贡献；如果只对某算法有效，说明 signal 和 objective strongly coupled。
- **Novelty**: 6/10.
- **Feasibility**: 中。需要 ReBRAC-lite 接入 sample weight。
- **Risk**: MEDIUM.
- **Contribution type**: empirical finding + method.
- **Pilot result**: SKIPPED.
- **Reviewer's likely objection**: 如果实验只在一个 env/seed 上，不足以支撑“reuse”。
- **Why we should do this**: 这是 ATLAS 成功后的扩展，不是第一步。

## Suggested Execution Order

1. Implement a teacher-label export path from existing SSAR/IQL cache:
   - input: D4RL batch or full dataset;
   - output: JSON/NPZ with per-transition `trusted_score`, `advantage`, optional `state_beta`;
   - no training yet.

2. Implement ATLAS selector:
   - small MLP: `(s, a) -> trusted_score`;
   - train supervised on teacher labels;
   - log label MSE/AUC/rank-correlation before RL training.

3. Run first 50k gate:
   - env: `hopper-medium-replay-v2`;
   - seed: 0;
   - eval episodes: 5;
   - compare against TD3+BC, ReBRAC-lite, IQL, CQL, cheap SSAR no-IQL, SSAR cached.

4. Only if ATLAS passes:
   - extend to 100k;
   - add dynamic beta/controller if 50k peak drops;
   - then consider seed1 or second replay env.

## What Counts As A Real Contribution

Weak claim to avoid:

> We ran SSAR / IQL and got high score.

Better claim:

> We show that SSAR's expensive trusted-action signal can be distilled or approximated by a lightweight selector, preserving a meaningful fraction of the benefit at a much lower preprocessing cost.

Minimum evidence needed before this becomes paper-facing:

- ATLAS or Light-IQL selector beats ReBRAC-lite and CQL on the first gate.
- 100k curve does not collapse like return-ranked filtering.
- One stability check: seed1 or second replay env.
- Runtime / cost comparison against full SSAR IQL-qv preselection.
- Ablation showing teacher label quality matters: random labels / return labels / online Q-gap labels fail.
